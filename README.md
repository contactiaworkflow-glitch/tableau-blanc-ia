# Tableau Blanc IA

Transformez un dessin au trait et une voix en vidéo « tableau blanc » : une main dessine votre image au feutre, au rythme de vos phrases. Gratuit, sans compte, sans filigrane, sans publicité.

**Ouvrir l'appli : https://contactiaworkflow-glitch.github.io/tableau-blanc-ia/**

## Ce que fait l'appli

- Une main réaliste trace le dessin au feutre ; l'encre n'apparaît que sous la pointe.
- Les scènes se calent toutes seules sur les phrases de votre voix.
- Une image avec plusieurs scènes côte à côte est découpée toute seule.
- Fond blanc ou vrai tableau, feutre noir, bleu, rouge ou vert, main gauche ou droite, zoom doux, transitions entre les scènes, son du feutre.
- Export MP4 1080p, 720p ou 480p, en 16:9 ou 9:16, avec la voix.

Tout se passe dans votre navigateur (Chrome ou Edge à jour) : vos images et votre voix ne quittent pas votre ordinateur.
